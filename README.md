# SaldoLeve

Aplicação de controle de despesas pessoais, em desenvolvimento.

## Funcionalidades planejadas

- Cadastro de despesas.
- Filtros por mês.
- Resumo dos gastos.
- Persistência dos dados.

## Desenvolvimento

- `main`: versões estáveis do projeto.
- `development`: desenvolvimento das funcionalidades.

As alterações prontas e testadas serão integradas à `main` por Pull Requests.
